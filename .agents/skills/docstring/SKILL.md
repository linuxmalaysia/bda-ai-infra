# Docstring & Function Reference Skill

This skill ensures 100% docstring compliance across Python (PEP-257 Google-style) and Node.js / JavaScript / TypeScript files (JSDoc).

## Executable Action

When executed:
1. Inspect Python files and inject PEP-257 Google-style docstrings into all functions, classes, and modules missing docstrings.
2. Inspect Node.js, JavaScript, and TypeScript files (`.js`, `.mjs`, `.ts`) and inject JSDoc comments into all functions, methods, and classes missing documentation.
